# Hand-Press Printing House

A point-and-click browser simulation of an early modern (c. 1683) printing shop.
Set mirrored type from a historical case, impose a forme on the stone
(broadside, folio, quarto or octavo), print both sides on a hand press, then
fold the sheet into a book and watch the watermark travel with the paper.

No build step and no dependencies: open `index.html` in a browser.
Fonts (IM Fell family) load from Google Fonts; without a connection the page
falls back to a system serif.

The case lay is simplified from Joseph Moxon, *Mechanick Exercises* (1683).
